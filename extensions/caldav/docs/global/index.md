# CalDAV 与 CardDAV

CalDAV 扩展让日历应用、Tasks.org 和联系人应用通过 DAVx⁵ 双向同步 InKCre 中的信息。
日历和任务采用 CalDAV，联系人采用 CardDAV。启用后提供「InKCre 日历」「InKCre 任务」
和「InKCre 联系人」三个默认集合，也可以创建更多集合。

日历支持全天事件、时区、重复及单次例外和提醒。任务保留到期、完成、重复、提醒、
父子关系和客户端扩展属性。联系人保留多个电话、邮箱、地址、备注和内嵌照片。
停用扩展不会删除这些信息；重新启用后可以继续同步。

在 DAVx⁵ 中选择「使用 URL 和用户名登录」，输入部署提供的完整 `/caldav/` 地址、
用户名 `inkcre` 和 DAV 专用密码。允许需要的日历、联系人和 Tasks.org 权限，
然后勾选要同步的集合。在日历和联系人应用中创建对象时，选择该 DAVx⁵ 账户；
在 Tasks.org 中选择对应的 InKCre 任务列表。

按截图操作见[连接 Android 手机](android)。

通过 DAVx⁵ 同步时，Tasks.org 不能创建、重命名或删除远程列表；使用 DAVx⁵ 的集合管理。
不要同时在 Tasks.org 中为同一个服务重复配置直接 CalDAV 同步。

同一个部署的客户端共享全部 DAV 信息，不提供用户隔离或集合级权限。此扩展不发送
会议邀请邮件，也不新增网页日历界面。外部连接应使用 HTTPS。
